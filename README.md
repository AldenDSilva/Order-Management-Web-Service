# Order-Management-Web-Service

## Description
A RESTful web service for a drop shipping retailer. The web service is an order management system that uses an external wholesaler service. 

## Functionality
The system allows operators of the service to be able to add products to the sales list from the wholesaler’s service, update prices of products, view orders placed by customers, change the status of the orders (shipped or out of stock), and view the revenue generated by a customer. 

It also allows customers to view products up for sale, place orders, check on previously made orders and view their status, and cancel orders that or not shipped yet.

REST design principles:
resource identification, addressability, resource representation, statelessness, uniform interface, and HATEOAS

## Key Features

-	Product management (add and update pricing from wholesaler)
-	Customer order creation, tracking, and cancellation
-	Order status management (shipped / out of stock)
-	Revenue tracking per customer
-	Integration with external wholesaler API

## Further Development
- The service may automatically change the status of an unshipped order to “out of stock” if
the wholesaler’s stock levels are too low to fulfil the order, or if the current wholesale price
is so high that the retailer would make a loss when fulfilling the order.
- When creating an order check with the wholesaler’s site to see if the price is more than
selling price also check the stock amount.
- The service does not use https as no personal data is being inputted, like customer
information.
